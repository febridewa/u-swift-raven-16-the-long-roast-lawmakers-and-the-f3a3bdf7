One satirical sentence, 163 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF — built for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert" bounty ($2 in USDC, top 10 paid).

> They will write the law that governs every algorithm on earth, just as soon as someone in the building works out which button turns their 400-page bill into a PDF.

The setup grants the lawmakers maximum authority, then the turn undercuts it with the file they cannot convert — and the file is their own 400-page bill, so the joke stays aimed at lawmakers and the rules they write. The punch lands on the last few words, it reads clean in one pass, and the specific detail (a 400-page bill, "which button") beats the worn tech-illiteracy clichés.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (override with `OUTPUT_DIR`).
